EQS – Equation Solver: Support

EQS solves the equations of engineering problems, with fluid properties, units, parametric tables and plots.

Contact

Write to butucea.stefan@gmail.com. Tell us your EQS version (Help → About EQS) and, if you can, attach the model file. We answer within two working days.

Start here

  • Learn EQS: Help → EQS Guide teaches EQS step by step.
  • Examples: File → Open Examples has more than 40 worked models.
  • Solve: press the ▶ button in the toolbar, or F2.

Trial and purchase

  • Help → Buy EQS… starts the free 14-day trial, buys EQS, or restores a purchase.
  • New Mac or new installation: click Restore Purchases, with the same Apple Account.
  • University licence: Help → License Status… → Install License File….

Folder access

The first time you open a model from a folder, EQS asks for access to that folder. A model keeps its tables, plots and diagram in files beside it, so EQS needs the folder. Click Allow. EQS asks only once for each folder.

Privacy

EQS collects no personal data. Read the privacy policy.
